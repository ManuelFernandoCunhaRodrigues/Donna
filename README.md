# Donna Concept Site

Site institucional estático criado para a Donna Concept, com direção visual inspirada nas referências do Instagram da marca.

## Estrutura

- `index.html`: página principal
- `styles.css`: identidade visual e responsividade
- `script.js`: menu mobile, header dinâmico e ícones
- `assets/`: imagens usadas no layout

## Como visualizar

Abra `index.html` no navegador ou rode um servidor local:

```bash
python -m http.server 5500 --bind 127.0.0.1
```

Depois acesse `http://127.0.0.1:5500/`.
